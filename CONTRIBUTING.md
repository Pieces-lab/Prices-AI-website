# Contributing

[→ 简体中文](CONTRIBUTING.zh-CN.md)

Thanks for helping collect personal websites for Pieces Lab. You can suggest your own site or another creator's site. A submission should help readers understand the person, the work, and what makes the website distinctive.

## Add a website

1. Check that the website is public, works on a current browser, and is not already listed in [README.md](README.md).
2. Copy [`templates/_template.md`](templates/_template.md) to `templates/<domain>.md` and replace the example text with specific, verifiable details. Use a GitHub username in the filename if the site has no stable domain.
3. Add a homepage screenshot to `templates/` as `<domain>-home.jpg` or `<domain>-home.png`. Use an image you created or have permission to submit. Keep the image readable and reasonably sized; the first entry uses 1280 × 720 pixels as an example.
4. Add the next number and a matching entry to both [README.md](README.md) and [README.zh-CN.md](README.zh-CN.md). Include the screenshot, live URL, source repository if available, reference document, and a short description of the site's highlights.
5. Open a pull request explaining which website you added and linking to its live page. Check that all local links and images render in GitHub's preview.

## Content guidelines

- Describe what is visible on the website. Leave unknown details out instead of guessing.
- Write original summaries and credit the site owner. Keep any contact details to information the owner has chosen to make public.
- Link to the author's repository when one exists. Do not copy their website source code into this repository.
- Keep the English and Simplified Chinese README entries aligned, including numbering and links.
- By submitting original text, you agree to publish that text under the repository's [CC BY 4.0 license](LICENSE). Third-party screenshots and other excluded assets keep their existing rights.

To apply to the organization itself, use [Join Pieces](https://github.com/Pieces-lab/Join-Pieces). Website submissions belong in this repository.
