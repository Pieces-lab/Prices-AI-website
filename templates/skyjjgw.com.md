### 网站结构与设计特点

1. **星夜序言**：全屏画作、个人介绍与玻璃质感导航，建立作品馆的视觉主题。
2. **四幅画框**：依次呈现“你好，skyjjgw”“作品与代码”“学习与实践手记”“画面背后的我”。
3. **画框内交互**：作品卡片可展开，手记可以翻阅；还提供画框全屏、上一幕与下一幕等浏览入口。
4. **可控制的浏览节奏**：可以切换自动浏览、暂停动态；源码中保留减少动态偏好的处理。
5. **从画面到代码**：通过网站、作品馆和 GitHub 链接，将视觉展示与真实项目资料连接起来。

个人站以 HTML / CSS / JavaScript 静态页面为基础，使用 Three.js 等浏览器端组件。个人资料仓库提供可直接静态部署的快照，预构建交互组件的完整重建配置不都包含在该快照中；需要改造模板时，请查看独立的 Starry Museum 模板仓库。
