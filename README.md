## Vision

A personal website is a space of your own. It can be a résumé, a digital garden, a portfolio, or a place to document ideas as they grow. Pieces Lab wants every member to have a place to tell their story and share their experiences, projects, and work. This repository brings those spaces together so others can discover the people behind them.

## Personal Website Templates

Personal websites can take many forms. This collection helps new creators explore different ways to introduce themselves, organize projects, and express a personal style before building their own space. Each template includes a homepage preview, a live link, a source repository when available, and a separate document describing the site's structure and highlights. More personal websites can be added to `templates/` over time.

## Add your website

1. Make sure your personal website is publicly accessible and contains the experiences, projects, or work you want to share.
2. Use [`templates/_template.md`](templates/_template.md) as a starting point. Add a Markdown file under `templates/`, named after your domain or GitHub username.
3. Add an entry under **Personal Website Templates** with the website link, related links, and a specific description. Submit the change through a pull request.

Share only information you want to make public. Authors maintain their websites and source code in their own repositories; this repository provides links and descriptions.
